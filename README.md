# Uifry

> ⚠️ **Важно:** Проект разработан **исключительно для десктопных экранов**. Адаптация под мобильные устройства и планшеты не выполнялась, поэтому на них отображение может быть некорректным.

---

## 📖 О проекте

**uifry™** – это одностраничный лендинг (landing page), созданный для демонстрации бренда, занимающегося доступным и комфортным жильём. Сайт представляет собой визуально насыщенную страницу с чёткими блоками, побуждающими пользователя к действию.

Проект стал моим первым опытом работы с фреймворком **Minista** – статическим генератором на основе JSX и Vite. Я использовал готовый стартер `friendly-frontend-starter`, чтобы быстро освоить файловую маршрутизацию, компонентный подход и сборку многостраничных приложений (в данном случае – одностраничного).

## 🧩 Использованный шаблон

За основу взят готовый стартер **friendly-frontend-starter** (версия без TypeScript) от разработчика **aleksanderlamkov**.

Шаблон включает:
- **Minista** — статический генератор с роутингом на основе файловой структуры;
- **Vite** — быстрая сборка и Hot Module Replacement;
- **JSX** — компонентный подход без React;
- **SCSS + PostCSS** — с автопрефиксингом и конвертацией `px` → `rem`;
- **ESLint, StyleLint, Prettier** — линтинг и форматирование кода.

Подробнее о шаблоне:  
- [Репозиторий на GitHub](https://github.com/aleksanderlamkov/friendly-frontend-starter)  
- Профиль автора: [aleksanderlamkov](https://github.com/aleksanderlamkov)

## Мои доработки относительно исходного шаблона

- **Удалены все примеры страниц и компонентов**, которые шли в стартере (демо-страницы, примеры стилей и т.п.), чтобы оставить только чистую структуру для лендинга.

- **Созданы собственные секции** для всех блоков лендинга (Hero, партнёры, выбор проекта, «What Is Llooktre?», Primary Homes, Testimonials, Footer) – каждая секция вынесена в отдельный компонент.

- **Добавлены новые пользовательские компоненты**:
  - **Слайдер** – реализован с использованием библиотеки **Swiper.js** для отображения карточек домов или других элементов (например, отзывов).
  - **Плавающий marquee-фон** – декоративный элемент с анимированной бегущей строкой, который служит фоновым украшением (реализован через CSS-анимацию или JavaScript).

- **Полностью переписан файл** `variables.scss` – все переменные (цвета, шрифты, отступы, брейкпоинты) заменены на те, что соответствуют фирменному стилю макета **uiFly™**.

- **Проведён полный анализ макета** – определены все размеры, пропорции, цветовые схемы и типография, что позволило точно воспроизвести дизайн.

- **Добавлена библиотека Swiper.js** – установлена через npm и интегрирована в компонент слайдера.

- **Структура папок** осталась практически без изменений – я сохранил стандартную организацию `src/` с папками `components`, `pages`, `styles` и т.д., чтобы не нарушать логику стартера.

## Важное ограничение

Проект создавался **только для десктопных экранов** с минимальной шириной **1280 пикселей**.  
**Рекомендуемый масштаб просмотра – 100%** (без зума).

Медиазапросы для планшетов и телефонов не прописывались, поэтому на устройствах с меньшим разрешением или при изменении масштаба вёрстка может «разваливаться» или выглядеть неопрятно.

## 📥 Как скачать и запустить

### Способ 1 – через `npm create` (рекомендуется)

Создайте проект с помощью `npm create`:

```bash
npm create friendly-frontend@latest
```

Для TypeScript-версии добавьте флаг `--ts`:

```bash
npm create friendly-frontend@latest -- --ts
```

## 🚀 Скрипты

```bash
npm run start         # Запуск в dev-режиме
npm run build         # Сборка
npm run preview       # Локальный просмотр сборки

npm run lint:js       # Проверка JS-кода
npm run lint:js:fix   # Автоисправление JS-кода
npm run lint:css      # Проверка CSS-кода
npm run lint:css:fix  # Автоисправление CSS-кода
npm run format        # Проверка форматирования
npm run format:fix    # Форматирование
npm run lint          # Полная проверка кода и форматирования без исправлений
npm run lint:fix      # Полная проверка с автоисправлением и форматированием
```
